
# Roadmap

## MVP

- Owner bootstrap and login
- Core module manifest validation
- Module catalog and install flow scaffold
- Knowledge-base CRUD scaffold

**Acceptance criteria:** a fresh installation can be set up, authenticated, and show an installed knowledge-base module with working API routes.

## V1

- RBAC management UI
- audit viewer
- content publish workflow
- search indexing and notifications

**Acceptance criteria:** operators can assign roles, trace privileged actions, publish KB content, and retrieve permission-filtered search results.

## V2

- forms engine UI and workflow bindings
- marketplace checkout and entitlements
- backup package automation

**Acceptance criteria:** forms trigger workflow instances, paid modules validate entitlements, and backup jobs produce restorable packages.

## V3

- external identity federation
- advanced reporting exports
- multi-module marketplace governance

**Acceptance criteria:** SSO-enabled organizations can operate the platform with enterprise access controls and module lifecycle reporting.
